The 1-minute and 5-minute archives exceed GitHub's regular file-size limit and are stored using Git LFS. For these two, use the GitHub download links above; a `raw.githubusercontent.com` URL points to the small LFS pointer file rather than the ZIP payload. The other three archives are ordinary Git files and their `raw.githubusercontent.com` links return the actual ZIP contents.

This repository does not add a separate data license or make claims about the files beyond preserving the supplied archives and recording their checksums.
