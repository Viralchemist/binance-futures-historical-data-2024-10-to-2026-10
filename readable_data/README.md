- [Machine-readable manifest](https://raw.githubusercontent.com/Viralchemist/binance-futures-historical-data-2024-10-to-2026-10/main/readable_data/manifest.csv)
- The original kline column order is preserved, with a leading `symbol` column added to each hourly CSV and preview.
- Funding CSV column names and rows are preserved from the source files.
- Source archives are listed in the parent repository README.
