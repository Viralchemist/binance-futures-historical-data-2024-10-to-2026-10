## Important limitations

The sweep is a simple 24-hour rolling high/low breach followed by a close back inside. Directional follow-through is negative forward close-to-close return after a high sweep, positive after a low sweep; rows without the full forward horizon are excluded. This is a descriptive event study, not a backtest of an executable strategy. It does not model entry confirmation, fees, slippage, funding PnL, or position sizing. The earlier proposed script used an incorrect taker column (`taker_buy_base`) and parsed millisecond timestamps without `unit="ms"`; these outputs use `taker_buy_volume` and correct UTC millisecond conversion.
